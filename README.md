## How I work

I run a solo-led studio, which means I own the whole line: the client conversation, the architecture decision, the shader, the deploy, and the call two months later when something breaks. That shapes how I build — I optimize for systems that survive without me babysitting them, and I reuse deliberately, so the second client of a given type costs a fraction of the first.

The bar I hold everything to is that the work has to be defensible on load. A site that takes four seconds to paint is a broken argument, no matter what the deck says.
